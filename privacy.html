Privacy Policy

Last updated: November 6, 2026

aivod ("the app") is a private tool its owner uses to upload videos to their own YouTube channel. This policy explains what data the app accesses and how it is handled.

YouTube API Services

The app uses YouTube API Services. By using the app, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Data the app accesses

  • YouTube upload permission (youtube.upload): used only to upload videos, with their titles, descriptions and tags, to the signed-in user's own channel.
  • YouTube read-only permission (youtube.readonly): used only to show the name of the signed-in channel so the user can confirm uploads go to the right place.

The app does not read, collect or store your videos, comments, subscribers, analytics, contacts, or any other account data.

How data is stored

The Google sign-in token is stored only on the owner's own computer, in a file readable only by that user. It is never sent to any server other than Google's. The app has no server or database of its own, and it does not sell, share or transfer Google user data to anyone.

Data retention and deletion

The sign-in token is kept on the owner's computer until it is deleted or access is revoked. Videos uploaded to YouTube remain on YouTube under the channel owner's control and can be deleted in YouTube Studio at any time. The app keeps a local list of the titles of videos it has published so it does not repeat topics; this list contains no Google account data.

Revoking access

You can revoke the app's access at any time from your Google Account third-party connections page (also reachable through Google's security settings). Deleting the local token file also removes the app's stored access.

Limited Use

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.
